# 📈 Smart SIP & Wealth Tracker

A responsive fintech web application built to calculate mutual fund Systematic Investment Plan (SIP) returns and manage an active personal investment portfolio.

## ✨ Features
- **Interactive SIP Simulator:** Real-time sliders for monthly investment, expected annual return rate, and investment horizon.
- **Visual Data Breakdown:** Dynamic Doughnut chart powered by Chart.js comparing total invested capital vs. wealth gained.
- **Portfolio Tracker:** Add multiple SIP funds (e.g., Nifty 50, Midcap 150) and track total monthly commitments.
- **Persistent Storage:** Uses browser `localStorage` so saved SIPs remain intact across page reloads.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Responsive Grid & Flexbox layout)
- **Vanilla JavaScript (ES6+)**
- **Chart.js** for financial data visualization

## 🚀 How to Run
1. Clone this repository: `git clone <your-repo-link>`
2. Open `index.html` in any modern web browser.
